# somethingchan

An authoritative and entirely wrong field guide to Git, GitHub, and GitLab.

## Rule #1

**No JavaScript. No scripts.** Every page sends a `Content-Security-Policy: script-src 'none'` so even an accident can't run.

## Pages

| file | what |
| --- | --- |
| `index.html` | the field guide |
| `lab.html` | contribution graph, 3D commit cube, CI pipeline, merge resolver, SVG filters, man page |
| `game.html` | *Rebase Dungeon*, a text adventure with inventory, built on `:target` + `:has()` |
| `support.html` | source + donate |
| `404.html` | lost object |
| `feed.xml` + `feed.xsl` | changelog rendered by XSLT |

## Languages
