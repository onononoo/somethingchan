where's the code?

the source code lives on github in the somethingchan repository. fork it. star it. open an issue that says "+1".

what's inside

  • index.html — html5
  • css/somethingchan.css — css (layers, nesting, @property, :has)
  • assets/*.svg — svg + smil animation
  • feed.xml + feed.xsl — xml + xslt
  • manifest.webmanifest — json
  • sitemap.xml, robots.txt, humans.txt
  • lab.html, game.html, 404.html — more html
  • css/lab.css — 3d transforms, :target game state
  • events.ics — icalendar
  • readme.md — markdown
  • .well-known/security.txt — rfc 9116
  • license, license.html — mit, © 2026 kai
  • js/index.html + css/js.css — the /js page: shouts at javascript using <noscript> + @media (scripting)
  • qa/index.html + css/qa.css — the faq as a css-only imageboard
  • ip/index.html + css/ip.css — your ip, bouncing (via a sandboxed icanhazip.com frame)
  • javascript — none
