thread no.2005 hidden (the javascript manifesto)
file: manifesto.svg (1 kb, 200x200)
the javascript manifestopinned kai ## developer 09/23/26(wed)21:30:00 no.2005 >>2006
things i believe, in order:

1. a website is a document. documents do not need a runtime.
2. every script is a download, a parse, a compile, and a new way to break.
3. html already ships buttons, links, forms, dialogs, accordions and popovers. use them.
4. css can hold state now. radios, checkboxes, :target, :has(). this whole site is proof.
5. a language where [] == ![] is true should not be trusted with your scroll wheel.
6. "but it needs js for interactivity." no it doesn't. go play gem-tac-toe.
7. the best line of javascript is the one you didn't write.

>what about when you actually need it
then use a little. somewhere else. not here.
