javascript (often abbreviated js, rarely forgiven) is a programming language that was created in ten days in 1995 and has been apologized for ever since.[citation needed] it runs in every web browser, which is how it spread.[citation needed] it is banned on somethingchansomethingchana website about git with 0 bytes of javascript., where every page sends script-src 'none'.[1]

contents
  1. history
  2. features
  3. reception
  4. alternatives

history

javascript was released in 1995. by 1996 people were already asking it to stop. in 2016, an 11-line package called left-pad was unpublished and builds across the ecosystem broke.[2] historians call this "tuesday".[citation needed]

features

javascript features include: adding numbers wrong, sorting numbers alphabetically, being unsure what this is, and node_modulesnode_modulesthe densest known object. 847 mb for "hello world".. it also has [] == ![], which evaluates to true, and nobody has recovered.[3]

reception

reception has been mixed, in the sense that everyone uses it and everyone is upset about it. kara eklundkara eklundmascot of somethingchan. strongly against javascript. has described it as "coal".[citation needed] the somethingchansomethingchana website about git with 0 bytes of javascript. hall of shame lists ten charges, all guilty.[4]

alternatives

html and csscssthe stylesheet language that runs this entire wiki.. this wiki has tabs, previews, footnotes, a random article button and a talk page, and runs zero javascript. see also: not using it.
