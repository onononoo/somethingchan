soytionary

filter with the chips. vote with the buttons. the tally stays pinned while you scroll.
gem n. / adj.
a good post, commit, or website. this site, for example.
zero javascript? total gem
coal n. / adj.
the opposite of gem. a bad post. a 2 mb bundle for a contact form.
"just add react" is pure coal
soot n.
mediocre coal. not bad enough to be coal, not good enough to be a gem. most commit messages.
"fix" as a commit message is soot
gemerald n.
a gem so good it upgrades. a merge with zero conflicts.
ci passed first try. gemerald
it's over / we're so back interj.
the two states of every developer. alternates every time ci runs.
tests red. it's over. tests green. we're so back
-jak suffix
makes anything into a soyjak variant. gitjak, rebasejak, nodejak.
he's doing the gitjak face at the merge conflict
fell for it again award n.
given to anyone who runs npm install expecting it to work this time.
updated one dependency, broke 40. fell for it again award
commit n. / v.
a snapshot. could be a gem, could be coal. usually soot titled "wip".
48 commits, all named "wip". it's over
rebase v.
rewriting history so your branch looks like a gem even though it was coal the whole time.
rebased 47 commits into 1. we're so back
force push v.
the chud move. overwrites everyone else's work. never on main.
git push --force on friday. absolute chud behavior
merge conflict n.
when two soyteens edit line 42. resolve by talking, or by crying.
<<<<<<< head. it's over
nusoy n.
a developer who has never seen a .git folder and thinks github is git.
nusoy asks "how do i download the github"
consoom v.
to install a package without reading it. then another. then 1,400 more.
consoom npm package. get excited for next npm package
framework n.
a javascript thing that will be replaced before you finish the tutorial. always coal.
new framework dropped. it's already over
javascript n.
coal. see /shame/ for the full rap sheet. banned on /qa/.
0.1 + 0.2 = 0.30000000000000004. coal
html + css n.
the gemerald stack. can do tabs, games, counters and this entire page. no js required.
css did the tally on this page. gem
