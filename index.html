The Three Species

Select a specimen. Flip the cards. Do not feed after midnight.

Git Versionidae · Habitat: hidden folders · Diet: diffs

Git is a small, nocturnal creature that lives inside a folder called .git and hoards every thought you have ever had about a file. It was discovered in 2005 when a man became so annoyed that he accidentally invented it. Git does not forget. Git does not forgive. Git merely rebases.

Brancheshover to reveal
Grown from the trunk in spring. A healthy repo has 3–4,000 branches named fix-final-2-REAL.
Commitshover to reveal
Sealed envelopes of regret, stamped with a 40-character hex name no human has read aloud.
HEADhover to reveal
Where Git thinks you are. Frequently detached. Do not panic; it grows back.
Stashhover to reveal
A drawer. Things go in. Things do not come out. 71% of stashes are never popped.

GitHub Mascot: octopus-cat of unknown legal status · Currency: green squares

GitHub is a large public aquarium where Git repositories are displayed for the public to stare at. Visitors leave small gold stars as tribute. Developers measure their spiritual worth by the density of green squares on their contribution graph, which is harvested annually like a rice paddy.

Pull Requestshover to reveal
Named for the ancient ritual of tugging code into main by hand.
Issueshover to reveal
A support group where strangers say "+1" to each other for eleven years.
Actionshover to reveal
Tiny robots running your tests in YAML, a language invented to be indented wrong.
Forkshover to reveal
Cutlery. Also copies. Mostly cutlery.

GitLab Mascot: a tanuki, probably · Motto: "Why not also that?"

GitLab is GitHub's cousin who went to laboratory school. It does everything, then several more things, including things you did not know software could do. Its pipelines are so long some have never been observed finishing. It says "merge request" because it prefers to ask rather than tug.

Merge Requestshover to reveal
Pull requests, but with better manners and a longer sidebar.
Pipelineshover to reveal
Plumbing. Your code enters one end. Something exits eventually.
Self-Hostinghover to reveal
Keep GitLab in your basement, where it grows to fill all available RAM.
Runnershover to reveal
Marathon athletes who run your jobs. Unionized as of 2024.

Command Dictionary

Exclusive accordion via <details name> — only one opens at a time. Pure HTML.
git init safe

Awakens the creature. Once performed in your home directory, it cannot be unseen by your shell prompt.

git add . mild

Feeds Git everything within reach, including node_modules, .env, and a 4GB video named final.mov.

git commit -m "stuff" safe

The industry-standard commit message. Alternates include "stuff 2", "fix", and "please".

git push --force lethal

Asserts dominance over coworkers. Rewrites shared history. Legally a declaration of war in 3 countries. See also: --force-with-lease, the polite knife.

git blame emotional

A detective story in which you are always the culprit.

git reflog occult

The underworld, where lost commits wait to be summoned. Speak their hash three times.

git bisect safe

Binary search for the exact moment things went wrong. Answer: Tuesday.

git cherry-pick mild

Take one commit from another branch. The other commits notice. They will remember.

git submodule update --init --recursive cursed

Summons repositories within repositories within repositories. The recursion does not end. It merely waits.

git gud unreleased

Not a real command. Yet. Tracked in issue #1, opened 2008.

A Brief & False History

  1. 1972 — Humans version files by naming them report_v2_FINAL_use_this.doc. Dark age begins.
  2. 2005 — Git is born out of pure spite. It learns to talk in hashes before it learns to walk.
  3. 2008 — GitHub opens the aquarium. The first star goes to a repo containing a README that says "hi".
  4. 2011 — GitLab arrives, looks at GitHub, and says "what if that, but also everything else."
  5. 2016 — The CI era begins. Nobody has seen their laptop fan stop since.
  6. 2020 — Arctic Code Vault buries repositories in permafrost for future civilizations to be confused by.
  7. 2026 — somethingchan launches with zero JavaScript. Browsers everywhere breathe a sigh of relief.

Frequently Asked Questions

Is it pronounced "git" or "jit"?

It is pronounced like a sigh.

What's the difference between merge and rebase?

Merge is telling the truth. Rebase is rewriting history so it looks like you always knew what you were doing.

I committed my password. What do I do?

Change the password. Then move to a new town.

Can I undo a commit?

Yes. There are nineteen ways, and each undoes something slightly different.

GitHub or GitLab?

Yes.

What languages is this site written in?

HTML, CSS, SVG, SMIL, MathML, XML, XSLT (see the changelog feed), JSON (manifest), iCalendar (holidays), Markdown (README.md) and plain text (humans.txt). JavaScript was not invited.

Why is there no JavaScript?

It was in a separate branch. That branch was never merged.
