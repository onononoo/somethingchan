git-yolo(1)git manualgit-yolo(1)

name

git-yolo — commit, push, deploy and leave the building

synopsis

git yolo [--friday] [--no-tests] [--blame=<coworker>] [--vacation-days=<n>]

description

stages everything, writes the commit message "yolo", force-pushes to every remote, and sets your slack status to "on a plane".

options

--friday
  only runs after 16:45 on a friday. required.

--no-tests
  redundant. implied.

--blame=<coworker>
  rewrites authorship of the commit. ethically dubious. technically impressive.

exit status

0 on success. you on failure.

see also

git-revert(1), git-reflog(1), therapy(7), linkedin(1)
